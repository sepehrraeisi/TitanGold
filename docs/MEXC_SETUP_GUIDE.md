## 🎯 مقدمه

MEXC یکی از بزرگترین صرافی‌های ارز دیجیتال است که امکان معامله خودکار و دستی را فراهم می‌کند. برای استفاده از قابلیت‌های Trading در TitanGold، نیاز به تنظیم API Keys دارید.

### ⚠️ نکات مهم قبل از شروع:

- ✅ API Keys شما **محرمانه** هستند و نباید با کسی به اشتراک گذاشته شوند
- ✅ فقط **Read** و **Trade** permissions را فعال کنید (نه Withdraw)
- ✅ از **IP Whitelist** استفاده کنید برای امنیت بیشتر
- ✅ برای تست، می‌توانید از **Testnet** استفاده کنید

## 📝 مراحل دریافت API Key از MEXC

### مرحله 1: ورود به حساب MEXC

1. به وب‌سایت [MEXC.com](https://www.mexc.com) بروید
2. وارد حساب کاربری خود شوید
3. اگر حساب ندارید، یک حساب جدید ایجاد کنید

### مرحله 2: دسترسی به بخش API Management

1. روی آیکون **پروفایل** (بالا سمت راست) کلیک کنید
2. از منو، گزینه **API Management** یا **API Keys** را انتخاب کنید
3. یا مستقیماً به این آدرس بروید: `https://www.mexc.com/user/api`

### مرحله 3: ایجاد API Key جدید

1. روی دکمه **Create API Key** یا **Create New API** کلیک کنید
2. یک **نام** برای API Key انتخاب کنید (مثلاً: `TitanGold Trading`)
3. **Permissions** را تنظیم کنید:
   - ✅ **Read** (خواندن اطلاعات)
   - ✅ **Trade** (معامله)
   - ❌ **Withdraw** (خروج وجه) - **نباید فعال باشد**
4. **IP Whitelist** را تنظیم کنید (اختیاری اما توصیه می‌شود):
   - IP سرور TitanGold خود را وارد کنید
   - یا برای تست، می‌توانید خالی بگذارید
5. روی **Create** یا **Confirm** کلیک کنید

### مرحله 4: ذخیره API Key و Secret

⚠️ **هشدار مهم**: Secret Key فقط یک بار نمایش داده می‌شود!

1. **API Key** را کپی کنید (مثلاً: `mexc_xxxxxxxxxxxxx`)
2. **Secret Key** را کپی کنید (مثلاً: `xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`)
3. این دو را در یک مکان امن ذخیره کنید
4. روی **I have saved it** کلیک کنید

### مرحله 5: فعال‌سازی API Key

1. در لیست API Keys، API Key جدید را پیدا کنید
2. مطمئن شوید که **Status** آن **Active** است
3. اگر غیرفعال است، روی **Enable** کلیک کنید

## ⚙️ تنظیم API Keys در TitanGold

### مرحله 1: دسترسی به بخش Settings

1. وارد پنل TitanGold شوید
2. از منوی سمت چپ، روی **Settings** کلیک کنید
3. تب **Connections** را انتخاب کنید
4. بخش **Exchange API Keys** را پیدا کنید

### مرحله 2: وارد کردن API Keys

1. در فیلد **MEXC API Key**، API Key کپی شده را وارد کنید
2. در فیلد **MEXC API Secret**، Secret Key کپی شده را وارد کنید
3. اگر می‌خواهید از **Testnet** استفاده کنید:
   - گزینه **Use Testnet** را فعال کنید
   - توجه: در Testnet، معاملات واقعی نیستند

### مرحله 3: تست اتصال

1. روی دکمه **Test Connection** کلیک کنید
2. منتظر بمانید تا تست انجام شود (معمولاً 2-5 ثانیه)
3. اگر موفق بود:
   - پیام **✅ Connection successful** نمایش داده می‌شود
   - اطلاعات حساب شما نمایش داده می‌شود
4. اگر ناموفق بود:
   - به بخش [مشکلات رایج](#مشکلات-رایج-و-راهحلها) مراجعه کنید

### مرحله 4: ذخیره تنظیمات

1. پس از موفقیت‌آمیز بودن تست، روی **Save Changes** کلیک کنید
2. پیام **✅ Settings saved successfully!** نمایش داده می‌شود
3. حالا می‌توانید از بخش **Trades** استفاده کنید

## ✅ تست اتصال

### تست خودکار

پس از وارد کردن API Keys، سیستم به صورت خودکار:
- اتصال را تست می‌کند
- موجودی حساب را بررسی می‌کند
- اطلاعات حساب را نمایش می‌دهد

### تست دستی

1. در بخش **Connections Settings**، روی **Test Connection** کلیک کنید
2. اگر موفق بود، اطلاعات زیر نمایش داده می‌شود:
   - موجودی USDT
   - موجودی سایر ارزها
   - آخرین بروزرسانی

### بررسی در بخش Trades

1. به بخش **Trades** بروید
2. تب **Manual Trades** را انتخاب کنید
3. اگر API Keys درست تنظیم شده باشند:
   - Order Book نمایش داده می‌شود
   - می‌توانید معامله انجام دهید
   - موجودی شما نمایش داده می‌شود

## 🔧 مشکلات رایج و راه‌حل‌ها

### مشکل 1: "Connection test failed" یا "Invalid API Key"

**علت‌های احتمالی:**
- API Key یا Secret Key اشتباه وارد شده
- API Key غیرفعال است
- IP Whitelist تنظیم شده و IP شما در لیست نیست

**راه‌حل:**
1. ✅ API Key و Secret را دوباره از MEXC کپی کنید
2. ✅ در MEXC، مطمئن شوید API Key **Active** است
3. ✅ IP Whitelist را بررسی کنید:
   - در MEXC، به API Management بروید
   - IP Whitelist را خالی کنید یا IP سرور را اضافه کنید
4. ✅ API Key را دوباره ایجاد کنید

### مشکل 2: "Permission denied" یا "Insufficient permissions"

**علت:**
- API Key فقط **Read** permission دارد
- برای Trading نیاز به **Trade** permission است

**راه‌حل:**
1. در MEXC، به API Management بروید
2. API Key را ویرایش کنید
3. **Trade** permission را فعال کنید
4. تغییرات را ذخیره کنید
5. در TitanGold دوباره تست کنید

### مشکل 3: "Balance not available" یا موجودی نمایش داده نمی‌شود

**علت‌های احتمالی:**
- اتصال به MEXC برقرار نیست
- API Key فقط Read permission دارد
- مشکل در شبکه یا سرور

**راه‌حل:**
1. ✅ اتصال اینترنت را بررسی کنید
2. ✅ API Key را دوباره تست کنید
3. ✅ در MEXC، مطمئن شوید API Key فعال است
4. ✅ صفحه را Refresh کنید

### مشکل 4: "Rate limit exceeded"

**علت:**
- تعداد درخواست‌های زیاد به MEXC API

**راه‌حل:**
1. ✅ چند دقیقه صبر کنید
2. ✅ تعداد درخواست‌ها را کاهش دهید
3. ✅ اگر مشکل ادامه داشت، با پشتیبانی تماس بگیرید

### مشکل 5: "Testnet connection failed"

**علت:**
- Testnet API Keys متفاوت از Mainnet است
- یا Testnet در دسترس نیست

**راه‌حل:**
1. ✅ از Mainnet استفاده کنید
2. ✅ یا Testnet را غیرفعال کنید

## 🔒 بهترین روش‌های امنیتی

### 1. استفاده از IP Whitelist

**چرا مهم است:**
- فقط از IP های مشخص شده می‌توان به API Key دسترسی داشت
- امنیت را به شدت افزایش می‌دهد

**نحوه تنظیم:**
1. IP سرور TitanGold خود را پیدا کنید
2. در MEXC، به API Management بروید
3. IP را به Whitelist اضافه کنید
4. فقط از IP های مورد اعتماد استفاده کنید

### 2. محدود کردن Permissions

**توصیه:**
- ✅ فقط **Read** و **Trade** را فعال کنید
- ❌ **Withdraw** را هرگز فعال نکنید
- این کار از خروج غیرمجاز وجه جلوگیری می‌کند

### 3. استفاده از API Key جداگانه برای TitanGold

**چرا:**
- اگر API Key به خطر بیفتد، می‌توانید فقط آن را غیرفعال کنید
- سایر API Keys شما امن می‌مانند

### 4. تغییر دوره‌ای API Keys

**توصیه:**
- هر 3-6 ماه یک بار API Key را تغییر دهید
- API Key قدیمی را حذف کنید

### 5. ذخیره امن API Keys

**نکات:**
- ❌ API Keys را در ایمیل یا پیامک ذخیره نکنید
- ✅ از Password Manager استفاده کنید
- ✅ API Keys را در کد یا Git commit نکنید

### 6. نظارت بر فعالیت API

**نحوه:**
1. در MEXC، به بخش **API Logs** بروید
2. فعالیت‌های API را بررسی کنید
3. اگر فعالیت مشکوک دیدید، فوراً API Key را غیرفعال کنید

## ❓ سوالات متداول (FAQ)

### Q1: آیا می‌توانم از Testnet استفاده کنم؟

**پاسخ:** بله، TitanGold از Testnet پشتیبانی می‌کند. برای فعال‌سازی:
1. در تنظیمات، گزینه **Use Testnet** را فعال کنید
2. API Keys Testnet را از MEXC دریافت کنید
3. توجه: در Testnet، معاملات واقعی نیستند

### Q2: آیا می‌توانم چند API Key داشته باشم؟

**پاسخ:** بله، می‌توانید چند API Key در MEXC ایجاد کنید، اما در TitanGold فقط یک API Key فعال می‌تواند باشد.

### Q3: اگر API Key را فراموش کنم چه کنم؟

**پاسخ:**
- Secret Key فقط یک بار نمایش داده می‌شود
- اگر فراموش کردید، باید API Key جدید ایجاد کنید
- API Key قدیمی را در MEXC حذف کنید

### Q4: آیا می‌توانم API Key را غیرفعال کنم؟

**پاسخ:** بله:
1. در MEXC، به API Management بروید
2. API Key را پیدا کنید
3. روی **Disable** کلیک کنید
4. یا در TitanGold، API Keys را پاک کنید

### Q5: آیا می‌توانم از API Key برای Withdraw استفاده کنم؟

**پاسخ:** 
- ❌ **توصیه نمی‌شود**
- برای امنیت بیشتر، Withdraw permission را فعال نکنید
- اگر نیاز به Withdraw دارید، از وب‌سایت MEXC استفاده کنید

### Q6: چرا موجودی من نمایش داده نمی‌شود؟

**پاسخ:** چند احتمال وجود دارد:
1. API Key فقط Read permission دارد (نیاز به Trade)
2. اتصال به MEXC برقرار نیست
3. موجودی شما صفر است
4. مشکل در شبکه یا سرور

### Q7: آیا می‌توانم API Key را در چند دستگاه استفاده کنم؟

**پاسخ:** بله، اما:
- اگر IP Whitelist فعال باشد، فقط از IP های مشخص شده می‌توانید استفاده کنید
- برای امنیت بیشتر، از IP Whitelist استفاده کنید

### Q8: آیا می‌توانم API Key را برای چند حساب MEXC استفاده کنم؟

**پاسخ:** خیر، هر API Key فقط برای یک حساب MEXC است.
