### راه‌حل:

3. تنظیم log rotation بهتر

---

## اقدامات فوری

### 1. پاک کردن Crash Reports
```bash
# حذف crash reports (22GB فضا آزاد می‌شود)
sudo rm -rf /var/lib/apport/*
sudo systemctl stop apport
sudo systemctl disable apport
```

### 2. بررسی و تعمیر Daily Report
```bash
# چک کردن سایز فایل لاگ
ls -lh /var/log/titangold-backup-rotation.log

# اگر خیلی بزرگ شده، rotate کن
sudo mv /var/log/titangold-backup-rotation.log /var/log/titangold-backup-rotation.log.old
sudo touch /var/log/titangold-backup-rotation.log
sudo chmod 644 /var/log/titangold-backup-rotation.log

# تست دستی
sudo /usr/local/bin/titangold-daily-report.sh
```

### 3. اضافه کردن Log Rotation
```bash
# ایجاد logrotate config
sudo tee /etc/logrotate.d/titangold-backup << 'EOF'
/var/log/titangold-backup*.log {
    daily
    rotate 7
    compress
    delaycompress
    missingok
    notifempty
    create 644 root root
}
EOF
```
